# PdfAsset & AdSlot entities + migration

_Part of epic **Database & migrations**._

## Description
Add `PdfAsset` (linked to Article, storing free/premium S3 keys + downloadId) and `AdSlot` (slotName, adClient, adSlotId, isActive) models with migrations.

## Acceptance criteria
- Given the migration runs, when inspecting the DB, then `PdfAsset` has a unique `downloadId` column and FK to `Article`.
- Given the migration runs, when inspecting the DB, then `AdSlot` has a unique `slotName` column.
- Given a PdfAsset is queried by `downloadId`, when it exists, then the associated Article is eagerly loadable via Prisma relation.

## Technical notes
downloadId generated as a short unique token (e.g. nanoid) at PDF upload time, used both in the /download/[id] route and stamped into the watermark.

## Dependencies
- Article entity + migration
