# Article entity + migration

_Part of epic **Database & migrations**._

## Description
Add the `Article` model (title, slug, categoryId FK, authorId FK, excerpt, contentMarkdown, tags, views, isPublished, seo fields, timestamps) with a migration.

## Acceptance criteria
- Given the migration runs, when inspecting the DB, then an `Article` table exists with a unique constraint on `slug` and FKs to `Category` and `User`.
- Given an Article is created via Prisma client, when `isPublished` is false, then it is excluded from any 'published articles' query helper.

## Technical notes
tags stored as Postgres text[] via Prisma. seo fields (metaTitle, metaDescription, keywords[]) as columns on Article, not a separate table.

## Dependencies
- Prisma setup + Category & User models with migration
