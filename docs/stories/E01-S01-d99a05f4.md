# Prisma setup + Category & User models with migration

_Part of epic **Database & migrations**._

## Description
Add Prisma to the project, configure `DATABASE_URL`-driven connection, and create the initial migration for the `User` (admin/editor) and `Category` tables.

## Acceptance criteria
- Given a fresh clone with `DATABASE_URL` set, when `npx prisma migrate deploy` runs, then `User` and `Category` tables are created with the fields specified in the architecture doc.
- Given the Prisma client is generated, when imported in an API route, then it type-checks against the `User` and `Category` models.
- Given no `DATABASE_URL` is set, when the app boots, then it fails fast with an error naming `DATABASE_URL` as the required variable.

## Technical notes
Use Prisma ORM against Postgres. Store schema in prisma/schema.prisma. Role enum on User: admin|editor.
