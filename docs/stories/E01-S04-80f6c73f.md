# PremiumPurchase entity + migration

_Part of epic **Database & migrations**._

## Description
Add the `PremiumPurchase` model to track anonymous ad-free PDF purchases (provider, providerSessionId, amount, status, unwatermarkedLinkToken).

## Acceptance criteria
- Given the migration runs, when inspecting the DB, then `PremiumPurchase` has a FK to `Article` and no FK to `User` (purchases remain anonymous).
- Given a purchase row exists with status `paid`, when queried by `providerSessionId`, then exactly one row is returned.

## Technical notes
provider enum: razorpay|stripe. status enum: pending|paid|failed. unwatermarkedLinkToken is a one-time-use random token issued after payment confirmation.

## Dependencies
- Article entity + migration
